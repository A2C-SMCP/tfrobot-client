## macOS 桌面协同验收（待执行）

前提：运行本工作区对应的桌面构建，使用可用的测试账号/组织、两个可操作计算机和一个可聊天 Robot。涉及删除时使用专门创建的测试对象。无需新增业务 seed 结构；权限撤销需要有权操作测试账号的人员协助。

### 1. Chat 往返与后台更新

**做什么**：进入非首个会话，输入文本并添加附件，选中一个事件详情；切到计算机，期间让 Robot 产生更新，再返回，重复五次。

**复制用**：`issue-78-chat-draft`

**应该看到**：原 Robot/会话、消息、文本与附件、时间线位置和事件详情保持；隐藏期间的新消息出现且不重复。日志中的 `chat: host-mounted`、`chat: host-unmounted` 和 `chat: lifecycle` 不因普通导航重复创建/销毁；切换 Robot 才沿用既有替换行为。

**失败时贴什么回来**：往返前后页面状态、操作顺序及对应时间段的脱敏 `chat:` 日志。不要提供 token 或私密附件内容。

### 2. 内部 tab 与配置草稿

**做什么**：在第二台计算机设置中修改名称但不保存，依次切到 Skills、Inputs 和系统设置，再从菜单返回计算机；逐项执行上表所有有状态的内部页。

**复制用**：`issue-78-unsaved-name`

**应该看到**：返回原计算机和上次子页；General 原草稿保留，其他未编辑字段可刷新。未点击保存不产生保存成功反馈；隐藏页面没有弹窗。

**失败时贴什么回来**：起始对象、往返页面、输入值与返回后的值、是否发生保存提示。

### 3. 日志视图隔离

**做什么**：全局日志设置 keyword/级别/页码；计算机 A、B 的日志分别设置不同查询；往返三个视图。

**复制用**：`issue-78-global`、`issue-78-computer-a`、`issue-78-computer-b`

**应该看到**：每个视图恢复自己的输入、筛选、分页和展开项，查询结果不互相覆盖；返回时按当前查询重新读取新增日志，清理日志后相关视图按失效标记更新。

**失败时贴什么回来**：各视图查询和页码、返回后结果、操作时间和脱敏日志。

### 4. 弹窗与迟到动作

**做什么**：打开编辑器后切换页面；另行打开删除/导出确认，再离开；原生目录选择期间切换页面或身份后返回选择结果。

**复制用**：`issue-78-modal-draft`

**应该看到**：编辑输入保留，隐藏页没有浮层；危险确认已取消；返回不自动执行删除/导出/策略修改。

**失败时贴什么回来**：弹窗类型、切换顺序、返回后的提示和动作结果。

### 5. 身份、权限与对象失效

**做什么**：有草稿时切换账号或组织，登出后重新登录；在允许的测试环境撤销对象权限；删除当前测试计算机后返回其原页面；另在编辑 MCP/Input/Marketplace 时通过测试环境外部删除该编辑对象，再返回并等待刷新。

**复制用**：`issue-78-context-draft`

**应该看到**：旧身份的草稿和聊天资源清理，旧异步结果不进入新身份；删除计算机后回退到有效页面，旧对象缓存清理；已删除的内部配置对象关闭旧编辑器，不通过保存旧草稿将其重新创建。没有残留弹窗或自动提交。

**失败时贴什么回来**：身份/对象变化顺序、页面表现及对应脱敏事件日志。

### 6. 资源边界与退出

**做什么**：先记录聊天连接与监听的基线；重复菜单和 tab 往返十次，最后退出应用。

**复制用**：`issue-78-lifecycle`

**应该看到**：没有持续增长的 session/监听/后台任务；未访问页没有初始化操作；退出释放资源。

**失败时贴什么回来**：基线和往返后的生命周期日志、退出前后观察结果。
